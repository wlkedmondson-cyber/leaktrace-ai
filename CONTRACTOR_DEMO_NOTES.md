
# LeakTrace AI — Contractor Demo

## Positioning
AI-assisted water intrusion investigation platform.

NOT:
- replacing roofers
- automated roofing

YES:
- faster diagnosis
- fewer callbacks
- better insurance documentation
- stronger customer confidence

## Demo Flow
1. Start investigation
2. Choose roof system
3. Enter leak symptoms
4. Upload evidence photos
5. Run AI analysis
6. Show probable source + confidence

## Key Features
- Roof-system-specific logic
- Consumer / Contractor / Insurance modes
- Confidence scoring
- Guided investigation workflow
- Water intrusion intelligence
